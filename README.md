# LaundryMate

This project contains the LaundryMate workspace structure for research, fieldwork notes, data, and project documentation.

## Structure

- `research.md` — background research and findings
- `fieldwork.md` — notes from on-site or practical work
- `data.csv` — raw or processed project data
- `reflection.md` — personal or team reflections
- `frontend/` — client-side application
- `backend/` — server-side application

## Purpose

LaundryMate is a project for managing laundry-related workflows, data collection, and user-facing functionality.
